# Audit follow-up contract

The executive Audit describes the current proposal and recommends evidence or administrative additions. Recommendations do not independently prevent downloading a reviewed pair. Material conflicts and publication permissions remain enforced by delivery review.

Each newly generated recommendation has a Studio destination: research period, filing details, candidate profile, matter evidence or client referees. The same normalized action list supplies Word and Studio. Existing letters retain navigation through a compatibility adapter; an unknown recommendation opens the matter editor rather than disappearing.

Saving returns to the Audit. The UI records information supplied, not a claim that the recommendation has been resolved. Resolution requires checking the revised documents. Saves use owner authorization, revision checks and a transaction. Unchanged relevant fields do not mark an action answered. Stale or invented action IDs are rejected.

Additional matter facts require provenance and preserve the uploaded extract. Internal referee contact notes are available to the Audit writer/reviewer, not the selector or public Submission writer. Adding references invalidates the Audit and final review, retaining matching selection/development checkpoints. Changes to substantive matter evidence must reconsider dependent strategy and drafting.

Before edits invalidate approval, preserve the exact approved pair only if its input hash and both file hashes match. Historical downloads are owner-scoped and explicitly named as earlier versions, without claiming they include new information. They never grant approval to the edited draft.

Regression coverage: action destinations, reload persistence, unchanged inputs, stale saves, unknown IDs, source preservation, internal reference scoping, stage reuse, Word/UI action agreement and historical byte integrity. Product acceptance additionally requires browser navigation and save/return checks; unit tests alone do not establish the quality of real submissions.
