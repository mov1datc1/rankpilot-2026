# Bound original-source review proofs — v1.0.49

A full document review could be unusable because its proof paraphrased a source article ("A" instead of "The"), even when the reviewer judged the content adequate. Source-only optional industry warnings could also fail the generated-text defect contract after both final documents had already omitted both competing descriptors.

The exact-document editor now selects own-source passage references alongside its existing field-bound output references. The application restores original quotations before the unchanged evidence and semantic validators. Foreign, stale, missing and dual references fail closed. Every obligation, status, reason and independent acceptance check remains required. Full original sources remain visible; a selected citation never establishes semantic sufficiency. Passage catalogs are shared and source text is included only once in a separate table, rather than duplicated per obligation.

The existing optional-sector advisory normalizer additionally recognizes source-only warnings only when a canonical same-record register comparison is grounded, declares the sector nonessential, has no remaining claims, and both competing literal descriptors are absent from both exact documents. It retains that comparison and every acceptance decision and critical finding. Source changes, identity, outcomes, amounts, roles, user-owned questions and actual output claims do not qualify. The strict defect validator remains intact.

Validation: 656 Python tests, 506 Node tests (one skipped), and TypeScript passed, including six source-reference tests and two additional advisory boundary tests. An offline private fixture with 82 actual obligations restores own literal sources, preserves all failed statuses, and makes zero provider calls. An existing paid diagnostic becomes schema-valid after removing only two redundant source-only warnings; its acceptance, passed value and register checks remain identical. This is neither production approval nor a new semantic review. The source-reference schema/table adds input context; no reduction in per-call price or universal success is claimed. No model, token allowance, retry count or consumed ledger was changed.

The current failed trial and its unapproved document hashes are preserved privately. Publication does not resume exhausted jobs. Autonomous output quality and a fresh UI run remain separate acceptance requirements.
