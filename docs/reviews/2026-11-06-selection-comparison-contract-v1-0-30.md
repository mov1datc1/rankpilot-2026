# Explicit source pairs for selection comparisons v1.0.30

The latest fixed-version trial stopped in selection and produced no new Audit or final Submission. The reviewer challenged a selected matter's claim of distinct incremental capability by citing another selected mandate that already supplied that capability. The decision quotation belonged to the questioned matter, and the source quotation belonged to the explicitly identified peer. The old contract accepted only own-matter factual evidence or application rules, so it rejected this legitimate comparative proof twice as an invalid diagnostic.

Decision checks now distinguish own-source facts, application rules and portfolio comparisons. A comparison identifies its peer through an enum of actual dossier references. The target's exact comparative premise and original source support must bind; the peer's quotation must bind to that identified peer's original evidence and current decision. Peer facts never become facts of the target. The selection remains rejected and can enter bounded correction; evidence binding cannot approve it.

For a legacy check that already declares an Mxx peer in its explanation, the binder may recover the address without another model call only when the original quote uniquely matches that peer, the target premise is explicitly comparative, and the target has its own bound source support. Missing references, ambiguous sources, ordinary foreign factual quotations, fabricated target support and another decision's claim remain invalid. The correction receives both original sources while its edit schema still permits changing only the rejected decision. Capacity, hero, unaffected decisions, cumulative usage and recovery limits remain intact.

Validation: 524 Python tests, 486 Node passes and one skip; TypeScript and production build pass. Offline replay of the captured unchanged verdict recovers its explicit peer, preserves both quotes and all original sources/strategy, keeps selection rejected, and makes its bounded correction eligible. There was no new model generation or failed-job restart during diagnosis. Public fixtures are fictional.
