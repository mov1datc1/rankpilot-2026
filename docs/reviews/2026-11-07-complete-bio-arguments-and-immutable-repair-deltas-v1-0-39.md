# Complete biography arguments and immutable repair deltas v1.0.39

A biography could retain two valid personal links while understating another result that the Audit used to defend that person. A required source-grounded check now compares every included, supported biography with its actual Audit argument and with the outcomes of the work it describes. It does not require every peripheral mandate, confidential identities or metrics, invented results, or a nomination where the decision remains develop/do_not_present.

Targeted biography repairs now return only a typed output delta. Original profile references, source quotations, personally attributed matter bindings, category and identity cannot appear in that native output schema. Optional keyed output maps refresh only the existing public quotations; null retains them. The application merges the delta with immutable original fields and keeps the same validators. Legacy saved full-object corrections retain their existing strict source checks. This avoids rejecting a correct BIO merely because a full-object response unnecessarily transcribed or replaced an immutable source link.

A BIO-only output correction may omit external ranking benchmarks and selection methodology from its prompt because it cannot change the category or supporting evidence. Its own original sources and the base repair rules remain. Mixed repairs, category changes and selection retain their full context. The scope is derived from authorized mutable fields, not inferred from model instructions.

A redundant optional sector warning is retained as a trace advisory only when its original register/narrative comparison is grounded, it duplicates the structured register claim, its quote is literal in the exact document and its disputed term is absent from both exact documents. The canonical source comparison, passed flag, acceptance checks and execution proofs remain unchanged. Critical findings, human questions, identity, amounts, roles, aliases and outcomes cannot use this path. Incomplete or unknown provider responses remain blocked.

Shared voice rules now detect source lists/states/identifies commentary and statements that the submission shows/demonstrates something before the Audit is written, as well as on rendered text. Development/Audit dependency keys advance and artifact review becomes 26; renderer remains 21. There are no new budgets or retry allowances.

Validation: 599 Python tests; 497 Node passes and one skip; TypeScript checks. Fictional tests cover native immutable deltas, keyed proof preservation, nonasserted optional warning safeguards and full BIO/Audit consistency obligations. The preceding version completed one autonomous backend editorial run from saved extraction. A subsequent directed check found a real BIO omission; its paid corrective text was rejected by the old full-object binding contract. Unpaid replay under the new delta contract preserves every original field and validates the localized correction. That replay is not a new native generation, independent final review or fresh Word approval. No private source, provider reply or document is published.
