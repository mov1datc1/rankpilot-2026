# Isolated selection diagnostics and bounded field repair

Selection review now separates source-bound repair findings from unbound diagnoses. Bound findings can be repaired while unbound diagnoses remain pending. The next review covers the repaired decisions and pending diagnoses; passing proofs are reused only while their dependencies match. No unresolved diagnosis is turned into an advisory or an approved selection. Existing three-review/two-repair limits remain unchanged.

For a batch of prose-only findings, the repair transport contains patches for the target decisions' rationale and legal_understanding together. These fields express the same interpretation, so a rejected premise must not survive in its neighbouring prose. Matter source quotes, dispositions, hero, order and unrelated decisions are outside that transport. Both original sources are supplied for comparisons. A structural correction still needs explicit permitted dispositions; prose targets in a mixed structural batch cannot rewrite their original source quote. Every correction passes grounding and independent review.

A historical paid diagnostic can be rebound deterministically under the new diagnostic contract, without another model review or erased counters. One explicit continuation is available only for the same failed selection job, unchanged sources, known provider usage, a changed software build, remaining normal budget and remaining review/repair allowances. A ledger marker prevents another continuation. Enqueue preserves the job ID, cursor, checkpoint and accumulated ledger. Deployment alone starts no generation. The UI offers Continue preparation when eligible and explains that the original need not be uploaded again.

Cached verdict reuse and deterministic rebinding preserve the existing provider trace. Unknown provider outcomes remain quarantined; this change does not recover them or increase budgets. The original failure history is retained in the rebind report. A locally rebound rejection only enables repair, never release approval.

Existing semantic tests use the field transport while retaining their behavioural assertions.
