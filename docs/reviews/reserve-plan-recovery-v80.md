# Reserve comparison construction and continuation

A shared plan could return fewer reserve comparisons than the validator required. The planning instruction omitted exhaustive internal coverage, and a list schema accepted incomplete coverage. The constructor then treated that localized omission as an unrecoverable response.

Planning now compiles one required slot per reserve from the immutable selection. Visibility in the executive Audit is a separate decision. The same coverage rules validate the plan. Source identities remain application-owned.

A retained failed plan is eligible for one scoped completion only when its sole defects concern missing comparisons/visibility. The engine verifies the original source and content hashes and all other plan obligations before any call. Completion requests only missing comparisons, appends them to the valid ones and resumes writing. A second failed completion cannot replenish its allowance through another click or deployment.

Studio offers Continue preparation on the same existing job after the fixed deployment. The transaction preserves the cursor, sources, snapshot and usage ledger; duplicate requests reuse that job. Reading status does not launch work.
