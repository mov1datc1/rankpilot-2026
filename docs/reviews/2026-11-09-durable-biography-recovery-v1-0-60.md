# Durable continuation of targeted editorial repairs

Splitting biography recovery by person still placed all requests inside one stage deadline. A later request could start with only a small fraction of its normal timeout remaining, creating an unknown provider outcome and stopping the job. Residual corrections now persist after the first repair and run one existing authorized group per subsequent worker step. The same job, cursor, source ownership, token ledger and one residual attempt per field are retained. No fresh drafting, budget extension or extra recovery round is introduced.

The saved proposal is hash bound, queued groups are disjoint, completed paths cannot be replayed, and the worker checks source freshness and budget before each request. A failed or unknown response retains completed deltas and stops the remaining groups. The complete development validators and independent final document review remain required. A saved continuation is never an approved delivery.

Biography diagnostics now identify missing profile references, the rejected output quotation and the precise editorial phrase. Output-only quotation binding recognizes a unique span when the same person's subject changes between their name and a pronoun, or when an unchanged sentence becomes a clause. Preservation uses that same boundary. Source quotations are unchanged; altered actors, predicates, negation, tense, figures and ambiguous matches remain invalid.

Validation: 736 Python tests, 514 Node tests with one existing skip, and TypeScript. Added regressions cover serialized multi-step continuation, cumulative billing, unknown outcomes, stale proposals, repeated groups, graph persistence, worker cursor preservation, and conservative output bindings. Existing paid-response replay improves output binding and still rejects omitted credentials and editorial voice. These checks do not establish quality of a new final Word pair; a fixed deployed run and content comparison remain necessary.
