# Source-owned construction contracts — v1.0.79

A shared editorial plan could omit a source-confirmed lead mandate while downstream B9 validation required it. Because decisions were frozen before writing, the BIO writer could not supply a valid link for that mandatory work. Construction now completes the support set from the same canonical lead/participation requirements used by validation before freezing the plan. This records lead responsibility or team membership only; it never attributes every firm action to a person, changes nomination/category or admits excluded work.

The application now owns original profile unit references/quotes, mandate identities and institutional argument indices. Structured writing outputs use canonical keyed slots. Every profile unit remains accounted for, each mandatory personal mandate requires an output passage, and both institutional fields execute the same argument keys. The writer still owns substantive prose, source-supported entity relationships and actual public quotations. Existing privacy, source, depth and independent semantic checks remain in place. A profile can contain several entity decisions linked to the same original unit.

Matter writing receives an explicit output slot for every selected matter and execution passages for its planned material anchors. These passages are checked against the actual narrative. A malformed ancillary passage is recorded as unverified without freezing usable prose or starting an additional model call. Literal binding is not semantic approval. The privacy brief retains all registered identity variants and resolved route fields accepted by the existing validator.

New first-construction telemetry binds obligations to their original field/source hashes. Existing field-review calls record their first results before repair. Later repaired text cannot overwrite failed first-pass checks. Partial coverage produces no success percentage. The measure covers development source-field obligations only; whole-pair Audit/Submission quality remains a separate later evaluation. The 90% target is an evaluation objective, not a new release gate or claimed result.

Existing durable construction continuations retain their original output contract; new constructions select source-owned bindings explicitly. Completed unit identities, token history and original records are preserved. No new model calls, retry allowances, model downgrade or reduction of B9/B10/C2 depth is introduced.

Validation includes adversarial omissions, foreign identities, immutable source quotations, multiple entities, institutional completeness, source-preserving old checkpoints and first-review accounting. An offline reproduction against v78 confirms that the old planner accepted an omitted mandatory mandate. Replaying saved prose completes all construction units with unchanged source data and still reports known old content defects; it does not demonstrate fresh generative quality or a measured 90% success rate.
