# Typed residual recovery — v1.0.58

Structured source plans and institutional output links could fail their first correction and then be excluded from the residual repair because the scheduler accepted only text and candidate objects. The scheduler now admits every originally authorized typed field that still fails its own postconditions, keeping the same single residual attempt and original mutable-field scope.

Institutional diagnostics identify the precise rejected source or output quote. Output-link recovery receives the retained current B10, C2 and plan after the initial repair. It cannot change the source, selection, permissions or approval state. Invalid residual output remains rejected; bounded recovery does not certify document quality.

Validation: 727 Python tests; 512 Node tests passing, one existing skip; TypeScript check passing. Three regression tests cover omitted structured targets, an ineffective bounded retry, and output evidence refreshed after a concurrent prose correction. An offline replay of an existing response confirms that the previously omitted paths reach recovery, with no new provider generation. Final native document acceptance remains pending.
