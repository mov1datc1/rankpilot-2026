# Output binding and scoped repair outcomes v1.0.37

A fresh editorial run stopped after its bounded repair because output quotations differed from the actual biography by a resolved first/full name or the additive word “also”. The same repair both supplied a factual team-member biography and reported that an already non-nominated lawyer's category could not be established. That out-of-scope observation incorrectly blocked the generated biography task.

Output-only quote binding now recognizes the confirmed candidate's leading name-prefix expansion and that single additive insertion, returning only a unique literal span already in the same biography. It changes no prose or source quotation. Negation, tense, figures, roles, other actors and arbitrary synonym changes remain strict. Biography source units and personal mandate evidence still require their own original bindings.

Repairs return exactly one typed outcome per authorized field: corrected value or unresolved requested change. They cannot both apply and block that field, omit its outcome or invent another target. Source observations outside the permitted correction have a separate notes field. These notes preserve context without inventing facts, replacing a genuine blocked correction or granting document approval. The existing bounded residual correction uses the same contract and retains all usage.

One explicit, source-current continuation after a code change also covers these narrowly verified output-binding residuals. A pre-existing non-nominated pending category is eligible only for the specific legacy out-of-scope note, a corrected nonempty biography and source team-membership evidence. A missing credential, disputed outcome, actual nomination, unknown usage, unchanged build, exhausted budget or prior continuation cannot obtain another allowance. The same job, ledger, cursor and normal budget remain.
