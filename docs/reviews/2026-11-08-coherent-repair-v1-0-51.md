# Coherent biography preservation and recovery — v1.0.51

The prior repair could fail before applying candidate corrections because generated output references were protected even when the referenced words had never appeared in the BIO. Its residual retry also excluded whole-candidate corrections and required every failed field to be retryable together. These were incompatible contracts between preservation, application and recovery, not evidence of a provider outage.

The guard now protects only actual BIO spans bound to the person's own sources. Missing material work, credentials, source attribution, privacy and category assessments remain obligations of the original validators. A source-bound span that really exists still cannot be erased to obtain a pass. Up to 1,000 words remain available for warranted B9 content; length alone is not quality.

The single bounded residual repair supports both whole-candidate and restricted BIO targets. It preserves valid independent changes, recomputes residual obligations, retains original write scopes and source-dependent unresolved questions, and stops on unknown usage. A localized voice defect still receives only a localized correction. No extra retry allowance, budget reset, automatic restart, manual source edit or final-review bypass was added.

Individual nomination is read from the nomination decision, not inferred from a label such as “Not proposed”. Actual participation remains in the BIO; personally attributed substantive work still requires its proof. Terminal UI no longer advertises a nonexistent Audit or assumes every failed drafting attempt exhausted its token allowance.

Validation: 693 Python tests; 509 Node contract passes and one existing skip; TypeScript check. Nine new Python regressions cover absent output references, foreign evidence, credential loss, non-nominated participation, mixed repair scopes, independent unresolved fields, retry failure and unknown consumption. The UI regression covers a failure both before and after an Audit exists. A private replay of an already paid response preserves all eleven independently valid changes and routes precisely four candidate targets to one residual retry. It deliberately stops before a provider call; original input and paid trace remain unchanged.

Limits: zero new model generations. The replay proves routing and preservation, not successful native rewriting, better final Word quality, or autonomous acceptance. The prior failed run remains failed. Historical patches addressed individual boundaries, but lacked a regression combining invalid output references, full and narrow candidate repairs, and independent successful fields. This combined failure is now reproducible in automated tests and saved-response replay. A subsequent fixed-version acceptance test must judge the actual Submission and Audit together against the requested editorial criteria.
